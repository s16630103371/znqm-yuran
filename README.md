# ZNQM - AI Generation Studio

AI 驱动的图片与视频生成平台，赛博朋克风格个人网站。

## Features

- AI 图片生成（支持多种风格和尺寸）
- AI 视频生成
- 赛博朋克视觉风格
- 响应式设计
- 本地 API Key 管理

## Tech Stack

- 纯 HTML/CSS/JS，零依赖
- GitHub Pages 部署
- 自定义域名 znqm.cloud

## 部署

1. Star 本项目
2. 在 Settings → Pages 中启用 GitHub Pages
3. 设置自定义域名 znqm.cloud
4. 等待 DNS 生效

## API 集成

支持 Replicate、OpenAI、Stability AI 等 API，在页面底部配置 API Key 即可。
