API 配置

API Key 仅保存在你的浏览器本地，不会上传到任何服务器。

如何获取 API Key？

图片生成推荐使用 Replicate 的 stability-ai/sdxl 或 black-forest-labs/flux-dev 模型， 注册后在 API Tokens 页面获取 Key。

视频生成推荐 Replicate 的 lucataco/hotshot-xl 或 stability-ai/stable-video-diffusion， 使用同一个 API Key 即可。也支持 OpenAI DALL·E / Sora 和 Stability AI 的 API。
